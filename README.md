# Draconius

**A Talon creation.** A lightweight fantasy-leaning vanilla+ resource pack for Minecraft Java Edition.

## Current test target: 1.12.2

The first 1.12.2 preview ZIP is supplied with the project handoff.

- **Target:** Java Edition 1.12.2
- **Pack format:** 3
- **Texture scale:** 16×16 blocks and item icons; 64×32 armor layers
- **Archive size:** approximately 7 KiB
- **Style:** recognizably Minecraft, with cooler diamond tones, restrained gold details, and richer common blocks

### Included

- **Common terrain:** grass top and sides, dirt, stone, cobblestone, oak planks, sand, and gravel
- **Diamond armor:** helmet, chestplate, leggings, boots, and wearable armor-layer textures
- **Diamond tools:** pickaxe, shovel, and hoe

## Install

1. Download the Draconius 1.12.2 ZIP supplied with the project handoff. **Do not extract it.**
2. Open Minecraft Java Edition 1.12.2.
3. Choose **Options → Resource Packs → Open resource pack folder**.
4. Move the ZIP into that folder.
5. Return to Minecraft and move **Draconius** into the active column.

## Compatibility

This build is specifically for Java Edition 1.12.2. It uses pack format 3 and the legacy `textures/blocks` and `textures/items` paths. It is not compatible with modern 1.13+ clients; those need a separate export.

## Development status

The ZIP structure, metadata, legacy texture paths, and PNG dimensions have been checked. It has not yet been launched in Minecraft, so the first single-player test will confirm that the textures display and that the worn armor layers align correctly.
