# Draconius

**A Talon creation.** A lightweight fantasy-leaning vanilla+ resource pack for Minecraft Java Edition.

## Current test build: Minecraft 1.12.2

[**Download Draconius 1.12.2**](Builds/Draconius-1.12.2-Refined.zip)

- **Target:** Java Edition 1.12.2
- **Pack format:** 3
- **Texture scale:** 16×16 blocks and item icons; 64×32 worn-armor atlases
- **Archive size:** about 11 KB
- **Style:** familiar Minecraft shapes, deeper terrain shading, cool diamond tones, and restrained gold trim

### Included

- **Common terrain:** grass top and sides, dirt, stone, cobblestone, oak planks, sand, gravel, oak logs, log tops, and oak leaves
- **Diamond armor:** helmet, chestplate, leggings, boots, plus the textures used when armor is worn
- **Gathering tools:** diamond pickaxe, shovel, and hoe
- Custom pack icon

## Install

1. Download the ZIP above. **Do not extract it.**
2. Open Minecraft Java Edition 1.12.2.
3. Choose **Options → Resource Packs → Open resource pack folder**.
4. Move the ZIP into that folder.
5. Return to Minecraft and move **Draconius** into the active column.

## Compatibility

This build is specifically for Java Edition 1.12.2. It uses pack format 3 and the legacy `textures/blocks` and `textures/items` paths. Modern Minecraft versions need separate exports because their resource-pack formats and asset paths changed.

## Test status

The ZIP integrity, pack metadata, legacy filenames, PNG dimensions, and required armor files have been checked. It has **not** been launched inside Minecraft yet. The first single-player test should check block faces, inventory icons, and how the armor looks when equipped.
