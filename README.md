# Draconius

**A Talon creation.** A lightweight fantasy-leaning vanilla+ resource pack for Minecraft Java Edition.

## 1.12.2 test build

[Download Draconius for Minecraft 1.12.2](Builds/Draconius-1.12.2.zip)

- **Target:** Java Edition 1.12.2
- **Pack format:** 3
- **Texture scale:** 16×16 blocks and item icons; 64×32 armor layers
- **Archive size:** approximately 10 KiB
- **Style:** recognizable Minecraft textures, cooler diamond tones, restrained gold details, and richer common blocks

### Included

- **Common terrain:** grass top and sides, dirt, stone, cobblestone, oak planks, sand, and gravel
- **Diamond armor:** helmet, chestplate, leggings, boots, and wearable armor-layer textures
- **Diamond tools:** pickaxe, shovel, and hoe

## Install

1. Download the ZIP. **Do not extract it.**
2. Open Minecraft Java Edition 1.12.2.
3. Choose **Options → Resource Packs → Open resource pack folder**.
4. Move the ZIP into that folder.
5. Return to Minecraft and move **Draconius** into the active column.

## Compatibility

This build is specifically for Java Edition 1.12.2. It uses the legacy `textures/blocks` and `textures/items` paths and pack format 3. It is not the modern 1.21+ build.

## Development status

This is an early test build. The ZIP structure, pack metadata, texture paths, and PNG dimensions have been checked, but it has not yet been launched in Minecraft. Please test it in a single-player world and report any missing textures or armor alignment issues.
